# Agent Note：仅用于显示的工作折叠

Status: implemented

[English](2026-11-12-display-work-folding.md) | 中文

## 问题

插件拥有的消息可以在 Session 位置渲染，而不包含原生 Engine Turn。原生 Turn 折叠无法在不虚构执行记录的情况下折叠这些消息的中间回复、推理和工具。

## 决策

Chat Definition 通过 `displayWork` 来源标记及后端尾部状态选择加入。Chat Builder 按用户消息边界对已加载节点分组，并发布共享的显示摘要。控制器复用已有的折叠时机、回复保留及详细模式偏好；标识与 Engine Turn 相互独立。

最新交流在状态未知、运行中或被中断时保持展开。加载到真正的输入后，会替换不完整前缀的分组，而不改变来源节点 key。手动选择跟随最终回复标识。当分组依据不变时，流式文本复用已有摘要。

## 考虑过的替代方案

合成 Turn 与 Step 事件会暗示来源未提供的模型执行证据。由适配器复制 Chat 控制器则会重复展示策略。将摘要保留在 Chat 中，可以复用已有的偏好和展开状态所有者。

## 影响

未声明可选标记的来源保持原有渲染。显示分组不添加 Session 记录、上下文更改、时长或模型步骤计数。状态与节点成员关系仅描述已加载窗口，因此来源仍负责规范历史及运行状态的准确性。
